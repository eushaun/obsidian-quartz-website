Hello, my name is Shaun and welcome to my digital garden! I work as a Data Engineer in Sydney, Australia and this website is a hobby project that I've wanted to create for quite some time.

This website is built using markdown files managed through Obsidian. [Quartz](https://quartz.jzhao.xyz/) turns the markdown files into a HTML webpage and deployment is done using Cloudflare Pages.

Thought process on creating this website:
1. It's always been a personal goal to build a personal website from scratch, but unfortunately I have no knowledge of HTML/CSS/JavaScript.
2. Vibe coded my way to a prototype website using Claude and Qwen2.5, however I quickly realized this isn't maintainable as I still do not have the web dev skills to customize it.
3. At the same time, I started using Notion as a note-taking / project management tool. 
4. Notion works great, however the free version has its limits and the data is stored on their servers at the end of day.
5. Came across Obsidian, but didn't like that I have to pay for Obsidian Sync / Publish. Fortunately, Obsidian has an extensive community plugin support.
6. Self-hosted an instance of [Obsidian Livesync](https://github.com/vrtmrz/obsidian-livesync) on my home Raspberry Pi. At the same time, setup [Tailscale](https://tailscale.com/)for all my devices. This means I am now able to sync my notes (and plugins) across all devices in my Tailnet (and replacing Notion in the process).
7. Came across a [comment](https://www.reddit.com/r/ObsidianMD/comments/16e5jek/comment/jzv38ja/) by the CEO of Obsidian on different open source options for publishing Obsidian - started looking into Quartz.
8. Thanks to the clear and extensive Quartz documentation, here I am now.

I mainly wanted to build a simple website that: 
- Points to various side projects that I have been working on
- Create documentations on said side projects
- Able to share and access notes anywhere
- (Maybe in the future) Create a blog

Bonus features in using Obsidian to build the website:
- Combines my personal notes with the website
- A [[Bucket List]] to track TODOs and accomplishments
