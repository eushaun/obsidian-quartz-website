The goal of this project is to create an AI agent that is able to interact with NetSuite APIs to easily create transactions for end users. 

A frequent pain point that I encountered while working at my current company is that it is very tedious to manually create transactions using NetSuite UI, especially when there are over 20+ line items to add in a single transaction.

My vision for this agent is to create the transaction for the user, after given the necessary set of inputs and instructions. Once the transaction has been created, the agent should provide a link to the user for easy retrieval and validation.

The agent will be a chatbot deployed in the company Slack workspace for convenience.
